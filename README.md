# telegram-ai-bot

Telegram-бот на Python, который отвечает через PlusVibe API, когда к нему обращаются, и умеет генерировать картинки.

## Возможности

- Отвечает на сообщения в **личных чатах** безусловно; в **группах** — когда его **упоминают по имени** (`@username` или имя бота) или **цитируют** его сообщение.
- Ведёт короткую память диалога в рамках чата.
- По фразам «нарисуй…», «сгенерируй картинку…», «draw…» и т.п. генерирует изображение через `gpt-image-2:white` и отправляет его **цитатой** запроса с именем автора.
- По фразам «правда ли…», «проверь факт…», «fact check…» проверяет утверждения на достоверность через `perplexity/sonar` (статус, объяснение, источники).

## Установка

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env   # затем заполнить ключи
```

## Настройка (.env)

| Переменная | Описание |
|---|---|
| `TELEGRAM_BOT_TOKEN` | Токен от @BotFather (обязательно) |
| `PLUSVIBE_API_KEY` | Ключ PlusVibe API (обязательно) |
| `SYSTEM_PROMPT` | Системный промпт (необязательно) |
| `BOT_NAME` | Дополнительное имя для обращений (необязательно) |
| `CHAT_MODEL` | По умолчанию `gpt-6-luna` |
| `IMAGE_MODEL` | По умолчанию `gpt-image-2:white` |
| `FACTCHECK_MODEL` | Модель для проверки фактов, по умолчанию `perplexity/sonar` |
| `FACTCHECK_SYSTEM_PROMPT` | Системный промпт фактчекера (в коде — промпт по умолчанию) |
| `HISTORY_LIMIT` | Глубина памяти диалога, по умолчанию `20` |
| `MAX_TOKENS` | Лимит токенов на ответ основной модели; по умолчанию не ограничено (`0` — не отправлять параметр) |
| `LOG_FILE` | Файл лога, по умолчанию `bot.log`; пустое значение — только консоль |
| `LOG_MAX_BYTES` | Размер файла до ротации, по умолчанию `5242880` (5 МБ) |
| `LOG_BACKUPS` | Число старых логов, по умолчанию `3` |
| `BOT_MODE` | `polling` (по умолчанию, для локального компьютера) или `webhook` |
| `WEBHOOK_URL` | Публичный HTTPS-адрес бота (обязательно в режиме webhook) |
| `WEBHOOK_PATH` | Путь webhook, по умолчанию `webhook` |
| `WEBHOOK_LISTEN` | Интерфейс прослушивания, по умолчанию `0.0.0.0` |
| `WEBHOOK_PORT` | Порт, по умолчанию `8080` |
| `WEBHOOK_SECRET_TOKEN` | Секрет для проверки запросов от Telegram (необязательно) |
| `IMAGE_COOLDOWN_SECONDS` | Минимальный интервал между генерациями картинок, по умолчанию `600` (10 минут) |
| `IMAGE_COOLDOWN_PHRASES` | Фразы бота на время ожидания, через `\|` (по умолчанию 5 заготовленных в коде) |
| `ACK_PHRASES` | Мгновенные заглушки на время долгих операций (генерация картинки), через `\|` — по умолчанию 5 в коде |

## Запуск

```bash
source .venv/bin/activate
python bot.py
```

По умолчанию бот работает в режиме **polling** — подходит для локального компьютера.

### Режим webhook

```bash
BOT_MODE=webhook
WEBHOOK_URL=https://example.com   # публичный HTTPS-адрес
```

Вебхук будет вида `https://example.com/webhook`. Telegram требует HTTPS: для проверки на локальной машине поднимите туннель (например, `cloudflared` или `ngrok`), для сервера — reverse proxy (nginx/caddy) с TLS на `WEBHOOK_PORT`.

## Примечания

- Обращение по имени и цитаты доходят до бота даже с включённым privacy mode. Чтобы бот видел все сообщения чата (не требуется для работы), отключите privacy через @BotFather.
- Память диалога хранится в памяти процесса и сбрасывается при перезапуске.
- Ограничение на генерацию картинок глобальное на весь процесс бота: после успешной генерации повторная сработает не раньше, чем через `IMAGE_COOLDOWN_SECONDS`. Если запрос пришёл раньше, бот отвечает одной из фраз `IMAGE_COOLDOWN_PHRASES` с указанием оставшегося времени (цитатой запроса). Неудачные генерации лимит не тратят.
